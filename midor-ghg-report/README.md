## Key Findings (2024 Reporting Year)
- **Total GHG Emissions**: 19.94 million tCO₂e
  - Scope 1 (Direct): 2,813,318 tCO₂e
  - Scope 2 (Electricity): 199,898 tCO₂e
  - Scope 3 (Categories 7 + 11): 16,926,521 tCO₂e

- **Carbon Intensity**: 482 tCO₂e per kiloton of crude processed
- **Energy Intensity**: 0.047 tCO₂e per GJ of fired duty

## How to View
1. Open `index-magazine-updated.html` in a modern web browser (Chrome, Firefox, Edge)
2. Charts will render automatically using ECharts library
3. For best results, use Chrome or Edge

## How to Print to PDF
1. Open `index-magazine-updated.html` in Chrome or Edge
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
3. Select "Save as PDF" as the destination
4. Set:
   - Paper size: A4
   - Margins: Default
   - Scale: 100%
   - Background graphics: **ON** (to preserve colors and charts)
5. Click "Save"

The resulting PDF will be a professional magazine-style report with:
- Cover page
- Table of Contents
- 12 main sections with actual data
- 6 appendices
- Charts optimized for static PDF viewing
